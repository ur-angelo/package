FAQ

Good to know

Which Windows versions are supported?

Windows 10 and Windows 11 (64-bit). The launcher uses the Microsoft WebView2 runtime, which is already included with Windows 11 and most up to date Windows 10 systems.

Where are the files stored?

The launcher is installed in %LocalAppData%\HytaleLauncher and the game files live in %AppData%\Hytale.

How do updates work?

Each time the launcher starts it checks for a newer version. If there is one, it asks you to update, downloads it, installs it and restarts by itself.

How do I uninstall it?

Open Windows Settings, go to Apps, find Hytale and choose Uninstall. Your game files are not deleted.
